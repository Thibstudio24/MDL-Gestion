Stockage des fichiers

Où ranger les documents, photos de ménage et pièces jointes ? Le disque du serveur suffit pour démarrer (1 Go sur l'offre gratuite alwaysdata). Un fournisseur tiers gratuit et sans carte bancaire (Backblaze B2 : 10 Go offerts, Cloudflare R2, Supabase…) évite de saturer ce disque. Modifiable plus tard dans Réglages → Stockage.

Les champs « tiers » ne servent que si vous choisissez un fournisseur. Le disque du serveur reste le choix par défaut.

  1. Créer votre année scolaire dans Réglages → Années scolaires (les modules s'y rattachent ; le site n'en recrée plus jamais une tout seul).
  2. Configurer le cron alwaysdata : python manage.py mdl_cron toutes les heures.
  3. Renseigner le SMTP dans Réglages → Envois, puis envoyer un courriel de test.
  4. Vérifier les quotas dans Réglages → Quotas & purges (1 Go de disque sur l'offre gratuite).
  5. Générer les clés VAPID dans Réglages → PWA & push si vous voulez les notifications push.
